# P6-3 njavtv 站点任务设计（2026-09-24）

## 背景 / 目标

- 用户需求：新增 njavtv.com 站点任务（经 127.0.0.1:1080 代理访问，防管理员发现访问记录）
- 支持按番号、厂商、标签、类型爬取；支持番号提取；构建番号库（含 tktube 已抓取番号）
- 当前站点爬取基于番号去重；未知番号不去重但打特殊标记（人工复核）
- 站点实证：列表页 https://njavtv.com/dm265/en（200）、详情页 /dm<id>/en/<dvd_id>、
  元数据（title/dvd_id/maker/genre）、封面 fourhoi.com/<dvd_id>/cover-n.jpg、
  预览 fourhoi.com/<dvd_id>/preview.mp4（可下载）、完整视频 surrit.com m3u8（Cloudflare 保护）

## 组件与接口

- `pkg/idregistry/`（新）：番号库包
  - `registry.go`：IDRegistry（JSON 持久化，Load/Save/Add/Has/Count）
  - `extract.go`：ExtractCode（正则 [A-Z]{2,8}-\d{2,5} 提取番号）
  - `tktube_source.go`：FromTKTContent（扫描 tktube 任务对象提取番号）
  - 数据文件：`<work_dir>/idregistry.json`
- `task/njavtv/`（新）：njavtv 站点任务（booksite 模板 + 番号库）
  - `task.go`：NewTask（配置读取：代理、番号库路径、去重模式）
  - `adapter.go`：SiteAdapter（列表页分页 + 详情页解析 + 番号去重）
  - `registry.go`：番号库接入（查重/登记）
- 配置：`task.extra.proxy_url`（默认 http://127.0.0.1:1080）+ `task.extra.id_registry_path`

## 数据流

1. 启动：扫描 tktube 任务对象（title 提取番号）→ 番号库初始构建
2. 抓取：njavtv 列表页分页 → 详情页解析（title/dvd_id/maker/genre/cover/preview）
3. 番号去重：dvd_id 在番号库 → 跳过；不在 → 构建对象 + 打 metadata.special_review=true（人工复核标记）
4. 新番号登记入番号库
5. 下载：封面/预览经代理（fourhoi CDN）

## 错误处理

- 代理不可达：抓取失败返回错误（fail-closed）
- Cloudflare 挑战（403）：重试/记录失败
- 番号库写入失败：不阻塞抓取（仅记日志）

## 测试 + 变异点

- `pkg/idregistry`：提取正则测试（ATID-698/BBAN-603/大小写归一）、JSON 持久化、去重查询
- `task/njavtv`：adapter 解析测试（mock HTML）、番号去重逻辑测试
- **变异点**：删番号提取 → 去重失效测试红；删 special_review 标记 → 未知番号测试红；删代理 → 请求直连测试红

## 片划分

- P1：pkg/idregistry 番号库（提取/持久化/去重）
- P2：task/njavtv adapter（列表/详情/元数据解析）
- P3：tktube 番号扫描接入 + 代理下载

## 风险与零回归

- 仅新任务类型（njavtv），现有任务零影响
- 番号库仅新增 JSON 文件（work_dir 下），可删除重建
- 代理仅 njavtv 任务使用（其他任务行为不变）
